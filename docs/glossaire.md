# Glossaire

Termes utilisés dans les documents NexBSD, expliqués pour un lecteur non spécialiste.

| Terme | Définition simple |
|---|---|
| **ACL** | Liste de contrôle d'accès : qui a le droit de lire, écrire ou exécuter quoi. |
| **amd64** | Architecture des processeurs 64 bits d'Intel/AMD. Indispensable pour FreeBSD 15 (le 32 bits i386 a été retiré). |
| **B2G / Boot to Gecko** | Nom de projet de Firefox OS : un système où les applications sont des pages Web. |
| **bhyve** | Hyperviseur intégré à FreeBSD : permet de faire tourner d'autres systèmes dans des machines virtuelles. |
| **Bindery** | Annuaire « plat » des anciens NetWare (versions 2 et 3) : utilisateurs et groupes sans hiérarchie. |
| **Copyleft** | Licence qui impose de republier le code source des versions modifiées (ex. GPL). |
| **CUPS** | Système d'impression standard sous Unix. |
| **FreeBSD** | Système d'exploitation libre de la famille Unix/BSD, réputé pour son réseau et sa stabilité. |
| **Gaia** | L'interface utilisateur de Firefox OS (HTML/CSS/JavaScript), sous licence Apache 2.0. |
| **Gecko** | Le moteur de rendu Web de Mozilla (utilisé par Firefox). |
| **Gonk** | La couche matérielle de Firefox OS/KaiOS : noyau Linux + couche d'abstraction Android. Incompatible avec FreeBSD. |
| **IPX/SPX** | Protocoles réseau historiques de Novell NetWare. Retirés de FreeBSD en 2016 et de Linux en 2018. |
| **Jail** | Isolation légère sous FreeBSD : un environnement cloisonné partageant le noyau, comme une « prison » pour un service. |
| **KaiOS** | Système pour téléphones à clavier, dérivé de Firefox OS, propriétaire. |
| **LDAP** | Protocole d'annuaire : stocke utilisateurs, groupes, droits dans une arborescence interrogeable. |
| **MARS_NWE** | Émulateur libre de serveur NetWare (GPL), non maintenu depuis 2013. |
| **Memstick** | Image amorçable destinée à une clé USB. |
| **NCP** | NetWare Core Protocol : le protocole applicatif de NetWare (fichiers, droits, impression). |
| **NDS** | Novell Directory Services : annuaire hiérarchique de NetWare 4+, ancêtre conceptuel de LDAP/AD. |
| **NetWare** | Système de serveur de fichiers et d'annuaire de Novell, très répandu dans les années 1980-1990. |
| **pkg** | Gestionnaire de paquets binaires de FreeBSD. |
| **Ports** | Catalogue de recettes de compilation de FreeBSD (permet de compiler un logiciel avec des options). |
| **poudriere** | Outil de construction de paquets FreeBSD dans des environnements isolés. |
| **Prototype** | Première réalisation concrète destinée à prouver une faisabilité, pas à être utilisée en production. |
| **Samba** | Mise en œuvre libre du protocole SMB (partage de fichiers/imprimantes Windows) et d'Active Directory. |
| **SBOM** | Inventaire logiciel : liste de tous les composants et de leurs licences/versions. |
| **SMB** | Protocole de partage de fichiers et d'imprimantes, utilisé notamment par Windows. |
| **Trustee** | Dans NetWare, un utilisateur ou groupe auquel un droit est explicitement accordé sur un objet. |
| **UFS / ZFS** | Systèmes de fichiers de FreeBSD. ZFS offre les instantanés mais consomme plus de mémoire. |
| **WebKitGTK** | Moteur de rendu Web libre (issu de WebKit) utilisable comme bibliothèque dans une application. |
