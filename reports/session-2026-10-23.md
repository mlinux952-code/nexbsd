## 4. Résultats de recherche vérifiés (faits, avec source)

1. **FreeBSD 15.1-RELEASE** est la version courante (16 juin 2026), supportée jusqu'au 31 mars 2027 ; branche stable/15 jusqu'au 31 décembre 2029. 15.0 est déjà en fin de vie (30 septembre 2026). *(freebsd.org)*
2. FreeBSD 15.x **n'existe plus en i386** : i386, armv6 et powerpc 32 bits ont été retirés. *(annonce 15.0-RELEASE)*
3. **IPX a été retiré de FreeBSD 11.0** et de **Linux 4.17**. *(release notes FreeBSD 11.0 ; README MARS_NWE)*
4. **KaiOS est propriétaire**, partiellement publié, dépend de Gonk (noyau Linux + HAL Android) ; aucune image complète ne peut être construite publiquement. *(Wikipédia, kaios.dev, kaiostech)*
5. Les dépôts **Firefox OS** (`mozilla-b2g`, 251 dépôts) sont **archivés** depuis le 3 novembre 2021 ; **Gaia est sous Apache-2.0** (licence vérifiée dans le dépôt).
6. **MARS_NWE** (GPL-2.0) n'a pas évolué depuis **2013** et **exige IPX** ; son auteur avertit explicitement de l'existence de vulnérabilités.
7. **Samba** : versions maintenues 4.23.13 et 4.24.8, 4.25.0 disponible (septembre 2026) ; le port FreeBSD par défaut reste **4.16**, non maintenu en amont ; 4.19 et 4.20 sont dépréciés.
8. **OpenLDAP** : 2.7.1 (feature, 8 septembre 2026) et 2.6.15 (LTS) ; 2.5 en fin de vie au 15 janvier 2027 ; le seul port FreeBSD identifié est `openldap25-server` 2.5.20.
9. **WebKitGTK** est disponible et maintenu sous FreeBSD (`www/webkit2-gtk` 2.46.6) — alternative crédible au Gecko embarquable disparu.
10. **VirtualBox** ne supporte plus Windows 7 comme hôte depuis la version 6.1.0 (décembre 2019) : la virtualisation sur le PC de test n'est pas une voie fiable.

## 5. Faits nouveaux qui contredisent le concept initial

| Concept initial | Réalité vérifiée | Conséquence |
|---|---|---|
| « Réutiliser KaiOS » | système propriétaire, image non constructible, dépendance Linux/Android | KaiOS devient une **référence UX**, pas un composant |
| « Étudier Gecko comme moteur » | plus d'API d'intégration ; GeckoView = Android ; B2G archivé | moteur = **WebKitGTK** |
| « MARS_NWE pour la compatibilité NetWare » | nécessite IPX, absent de FreeBSD depuis 2010-2016, code gelé depuis 2013, dangereux | **rejeté** comme composant |
| « Samba = services modernes » | vrai, mais la version par défaut du port est non maintenue | **épingler ≥ 4.23** |
